#### Условие

Миша заполнял таблицу истинности логической функции:

$$F = \neg(x \to y) \lor (z \equiv w) \lor z$$

Успел заполнить только три строки — и то не подписал столбцы:

|  ?  |  ?  |  ?  |  ?  |  F  |
| :-: | :-: | :-: | :-: | :-: |
|  0  |  0  |     |     |  0  |
|     |     |  1  |     |  0  |
|     |  1  |  0  |     |  0  |

Нужно определить, в каком порядке стоят переменные $w$, $x$, $y$, $z$.

---

#### Стратегия Васи: не угадывать, а перебрать

Можно попробовать аналитически вывести порядок переменных. Вася попробовал. Вася посмотрел на функцию с импликацией и эквивалентностью. Вася решил не пробовать.

**Идея проще:** перебрать все $2^4 = 16$ комбинаций значений $x, y, z, w$, вычислить $F$ для каждой и выписать только те строки, где $F = 0$. Потом сравнить с таблицей Миши и найти совпадение.

Таблица Миши говорит, что при каком-то порядке переменных есть строки вида:

- `0 0 _ _` → $F = 0$
- `_ _ 1 _` → $F = 0$
- `_ 1 0 _` → $F = 0$

Нужно понять, какой порядок $(w, x, y, z)$ даёт именно такую картину.

---

#### Перевод формулы в Python

Сначала разберёмся с логическими операциями. В условии три из них:

- $\neg(x \to y)$ — отрицание импликации. Импликация $x \to y$ в Python записывается как `x <= y` (это работает для булевых значений: единственный случай когда $x \to y$ ложно — это $x=1, y=0$, и именно тогда $1 \leq 0$ тоже ложно)
- $(z \equiv w)$ — эквивалентность, то есть `z == w`
- $\lor$ — логическое ИЛИ, то есть `or`

Итоговая функция:

```python
f = not(x <= y) or (z == w) or z
```

Вася мог писать через `and`, `or`, `not` явно разворачивая каждый оператор. Но `x <= y` для импликации — классический трюк, который экономит строчку кода и выглядит элегантно. Вася иногда позволяет себе элегантность.

#### Полный перебор

```python
print("x y z w")
for x in (0, 1):
    for y in (0, 1):
        for z in (0, 1):
            for w in (0, 1):
                f = not(x <= y) or (z == w) or z
                if f == 0:
                    print(x, y, z, w)
```

Четыре вложенных цикла перебирают все $2^4 = 16$ комбинаций. Для каждой считаем $F$. Если $F = 0$ — выводим.

`print("x y z w")` в начале — просто шапка, чтобы не запутаться в выводе. Вася заботится о будущем Васе.

---

#### Сравниваем с таблицей Миши

Программа выведет все строки где $F = 0$. Среди них нужно найти три, которые совпадают с Мишиной таблицей — с учётом того, что порядок столбцов неизвестен.

Мишина таблица (заполненные ячейки):

| col1 | col2 | col3 | col4 |  F  |
| :--: | :--: | :--: | :--: | :-: |
|  0   |  0   |      |      |  0  |
|      |      |  1   |      |  0  |
|      |  1   |  0   |      |  0  |

Смотрим на вывод программы и ищем перестановку столбцов `x y z w`, при которой три строки с $F=0$ дают именно такую картину. Четвёртый столбец в каждой строке Миши пропущен — значит его значение нас не ограничивает.

Вася находит совпадение. Вася записывает порядок переменных. **Вася идёт проверять Мишину работу.**

#### Итоговый код целиком

```python
print("x y z w")
for x in (0, 1):
    for y in (0, 1):
        for z in (0, 1):
            for w in (0, 1):
                f = not(x <= y) or (z == w) or z
                if f == 0:
                    print(x, y, z, w)
```
