#### Шаг третий: кластеризация

Теперь нужно разбить очищенные точки на три кластера. Снова — **смотрим на график и проводим границы**.

```python
def clusterization(data):
    clasters = [[], [], []]  # три пустых кластера

    for point in data:
        if point[y] < -1.42 * point[x] + 10.856:
            clasters[0].append(point)
        elif point[y] < -1.223 * point[x] + 15.009 and point[x] < 9:
            clasters[1].append(point)
        else:
            clasters[2].append(point)

    return clasters
```

Каждая точка проверяется по двум разделяющим прямым:

- Первая прямая: $y = -1.42x + 10.856$
- Вторая прямая: $y = -1.223x + 15.009$ с дополнительным ограничением $x < 9$

Точка ниже первой прямой → кластер 0. Ниже второй и левее $x = 9$ → кластер 1. Всё остальное → кластер 2.

Дополнительное условие `point[x] < 9` нужно потому, что правее $x = 9$ вторая прямая начинает «захватывать» чужие точки. Вася увидел это на графике. **Без графика это не придумать.**

Откуда взялись коэффициенты $-1.42$ и $-1.223$? Вася взял две характерные точки на границе кластеров и посчитал наклон прямой через них. Формула наклона: $k = \dfrac{y_2 - y_1}{x_2 - x_1}$.

#### Шаг четвёртый: ищем центр кластера

Центр кластера — это **медоид**: точка внутри кластера, от которой сумма расстояний до всех остальных точек минимальна. Не геометрический центр, не среднее координат — а конкретная звезда из данных.

Расстояние между двумя точками — стандартная евклидова формула:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

```python
def dist(point_a, point_b):
    return (
        (point_b[x] - point_a[x]) ** 2 +
        (point_b[y] - point_a[y]) ** 2
    ) ** 0.5
```

И сам поиск центра:

```python
def get_center(claster):
    center = None
    min_sum = float('inf')  # начинаем с бесконечности — любая сумма будет меньше

    for point in claster:
        sum_ = sum(dist(point, other) for other in claster)
        if sum_ < min_sum:
            min_sum = sum_
            center = point

    return center
```

Для каждой точки считаем сумму расстояний до всех остальных точек кластера. Запоминаем точку с минимальной суммой. **Честный перебор.**

`float('inf')` — это бесконечность в Python. Удобный трюк для инициализации минимума: любое реальное число будет меньше.

```python
import matplotlib.pyplot as plt

x, y = 0, 1

def plot(data, color='blue'):
    x_values = [point[x] for point in data]
    y_values = [point[y] for point in data]
    plt.scatter(x_values, y_values, color=color)

def dist(point_a, point_b):
    return (
        (point_b[x] - point_a[x]) ** 2 +
        (point_b[y] - point_a[y]) ** 2
    ) ** 0.5

def clear_data(data):
    clear = []
    for point in data:
        if point[y] > point[x] + 5:
            continue
        if point[y] > -point[x] + 20:
            continue
        if point[y] < point[x] - 12:
            continue
        clear.append(point)
    return clear

def clusterization(data):
    clasters = [[], [], []]
    for point in data:
        if point[y] < -1.42 * point[x] + 10.856:
            clasters[0].append(point)
        elif point[y] < -1.223 * point[x] + 15.009 and point[x] < 9:
            clasters[1].append(point)
        else:
            clasters[2].append(point)
    return clasters

def get_center(claster):
    center = None
    min_sum = float('inf')
    for point in claster:
        sum_ = sum(dist(point, other) for other in claster)
        if sum_ < min_sum:
            min_sum = sum_
            center = point
    return center

with open("27B_18677.txt") as file:
    file.readline()
    data = [list(map(float, i.replace(",", ".").split())) for i in file.readlines()]

data = clear_data(data)
claster_1, claster_2, claster_3 = clusterization(data)

plot(claster_1, 'red')
plot(claster_2, 'black')
plot(claster_3, 'blue')

cent_1 = get_center(claster_1)
cent_2 = get_center(claster_2)
cent_3 = get_center(claster_3)

p_x = abs(int(((cent_1[x] + cent_2[x] + cent_3[x]) / 3) * 100_000))
p_y = abs(int(((cent_1[y] + cent_2[y] + cent_3[y]) / 3) * 100_000))

print(p_x, p_y)

plt.grid(True)
plt.show()
```
