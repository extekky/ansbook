#### Условие

На вход алгоритма подаётся натуральное число $N$. Алгоритм строит по нему новое число $R$ следующим образом:

1. Строится троичная запись числа $N$
2. Эта запись обрабатывается по правилу:
   - если **сумма цифр** троичной записи **кратна $9$** — к записи справа дописывается $2$
   - если **не кратна $9$** — дописывается троичная запись **остатка от деления суммы на $9$**
3. Результат переводится в десятичную систему и выводится на экран

**Примеры из условия:**

- $9 = 100_3$ → сумма цифр $= 1$, не кратна $9$, дописываем $1_3$ → $1001_3 = 28$
- $161 = 12222_3$ → сумма цифр $= 1 + 2 + 2 + 2 + 2 = 9$, кратна $9$, дописываем $2$ → $122222_3 = 485$

Найти **минимальное** $R$ при условии, что $N > 166$.

#### Шаг первый: перевод в троичную

Чтобы применить правило — нужна троичная запись числа. Вася пишет знакомую функцию перевода:

```python
def perevod(n, base):
    r = ''
    while n > 0:
        r = str(n % base) + r  # остаток — в начало строки
        n = n // base
    return r
```

Это уже старый знакомый — делим на основание, собираем остатки снизу вверх. Функция возвращает **строку**: `perevod(9, 3)` → `"100"`, `perevod(161, 3)` → `"12222"`.

Почему строку, а не список? Потому что дальше нам понадобится считать символы и склеивать строки. Со строкой это удобнее.

> Биба и Боба работают со списками и умеют в любое основание. Но здесь основание $3$, цифры только $0$, $1$, $2$ — строка справляется отлично. Вася использует правильный инструмент для правильной задачи. Вася мудреет.

#### Шаг второй: считаем сумму цифр

```python
summ = n_bin.count('1') + n_bin.count('2') * 2
```

Хитрый способ посчитать сумму цифр троичного числа без цикла:

- `n_bin.count('1')` — количество единиц × 1
- `n_bin.count('2') * 2` — количество двоек × 2
- Нули не трогаем — они ничего не добавляют

**Пример:** `"12222"` → $1 \cdot 1 + 4 \cdot 2 = 9$

Вася мог написать цикл `for digit in n_bin: summ += int(digit)`. Но эта версия красивее. Вася иногда позволяет себе красоту.

#### Шаг третий: применяем правило из условия

```python
if summ % 9 == 0:
    n_bin = n_bin + "2"
else:
    n_bin = n_bin + perevod(summ % 9, 3)
```

Дословный перевод условия задачи в код:

- Сумма кратна $9$? Дописываем `"2"` справа
- Не кратна? Считаем остаток `summ % 9`, переводим его в троичную и дописываем

Заметьте: `perevod` вызывается второй раз — теперь уже для самого остатка. Одна функция, два применения. Вася доволен своей экономностью.

#### Шаг четвёртый: переводим обратно в десятичную

```python
massive.append(int(n_bin, 3))
```

После всех манипуляций `n_bin` — это строка вида `"1001"` или `"122222"`. Нужно перевести её обратно в десятичное число.

Python умеет это сам: `int("1001", 3)` говорит «воспринимай строку как число в троичной системе» и возвращает `28`. Встроенная функция — Боба в отпуске, справляемся без неё.

Результат кладём в список `massive`.

#### Итоговый код целиком

```python
def perevod(n, base):
    r = ''
    while n > 0:
        r = str(n % base) + r
        n = n // base
    return r

massive = []
for n in range(167, 1000):
    n_bin = perevod(n, 3)
    summ = n_bin.count('1') + n_bin.count('2') * 2
    if summ % 9 == 0:
        n_bin = n_bin + "2"
    else:
        n_bin = n_bin + perevod(summ % 9, 3)
    massive.append(int(n_bin, 3))

massive = sorted(massive)
print(massive[0])
```

Вася запускает. Программа думает мгновение. Программа выдаёт ответ.
