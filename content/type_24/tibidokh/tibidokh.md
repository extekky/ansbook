#### №21717 на КЕГЭ

Вася открывает условие. Вася видит слово **"скользящее окно"**. Вася представляет окно. Окно скользит. Вася скользит следом.

---

#### Условие

Текстовый файл состоит из символов $F$, $G$, $Q$, $R$, $S$ и $W$. Найти **минимальное количество идущих подряд символов**, среди которых подстрока $RSQ$ встречается **ровно $130$ раз**, при этом искомая последовательность **не оканчивается** символом $Q$.

---

#### Метод скользящего окна: что это вообще такое

Прежде чем писать код, Вася разбирается с методом. Потому что без понимания идеи код — это просто буквы.

Представь длинную строку символов. Нужно найти в ней отрезок, содержащий ровно $130$ вхождений `RSQ`. Можно действовать в лоб: перебрать все возможные начала и концы отрезка и проверить каждый. Это работает, но медленно — количество пар $(начало,\ конец)$ растёт квадратично.

**Скользящее окно** умнее. Идея: зафиксировать количество `RSQ` внутри окна равным $130$ и просто **двигать окно** по строке, не пересчитывая всё заново. Окно сдвинулось — убрали одно `RSQ` слева, добавили одно справа. Длина окна меняется, количество `RSQ` внутри — нет.

Вася понял. Вася идёт писать код.

---

#### Шаг первый: читаем файл и задаём параметры

```python
with open("24_21717.txt", "r") as file:
    data = file.readline()

notEnd = 'Q'    # символ, на который не должна оканчиваться последовательность
repeat = 130    # сколько раз RSQ должна встретиться
subStr = 'RSQ'  # искомая подстрока

lenSubStr = len(subStr)  # 3
lenData = len(data)
```

Всё вынесено в переменные — если задача изменится (другая подстрока, другое количество), менять нужно только три строчки сверху. Вася думает о будущем Васе. Будущий Вася скажет спасибо.

---

#### Шаг второй: находим все вхождения RSQ

```python
indexes = []
for i in range(len(data) - lenSubStr + 1):
    if data[i : i + lenSubStr] == subStr:
        indexes.append(i)
```

Проходим по всей строке и ищем каждое вхождение `RSQ`. Если нашли — запоминаем индекс начала (то есть позицию `R`).

`range(len(data) - lenSubStr + 1)` — цикл останавливается так, чтобы последний срез `data[i : i + 3]` не вылез за пределы строки. Вася помнит про границы. Вася не получает `IndexError`.

**Пример:** для строки `"RSQWRSQRSQ"` список `indexes` будет `[0, 4, 7]` — три позиции трёх `RSQ`.

После этого шага у Васи есть список всех позиций `RSQ`. Теперь можно двигать окно.

---

#### Шаг третий: скользим окном по списку позиций

```python
minLen = float('inf')

for i in range(len(indexes) - repeat + 1):
    bgn = indexes[i]               # начало окна: первый R первого RSQ
    end = indexes[i + repeat - 1]  # начало последнего RSQ в окне
```

`float('inf')` — бесконечность. Любая реальная длина будет меньше. Удобный способ инициализировать минимум.

Цикл перебирает все возможные **начала** окна: окно из $130$ вхождений `RSQ` начинается с `indexes[i]` и заканчивается с `indexes[i + 129]`. На каждом шаге окно сдвигается на одну `RSQ` вправо.

---

#### Шаг четвёртый: разбираемся с хвостом

Вот тут начинается самое интересное. После последнего `RSQ` в окне может стоять хвост из `Q`. Например:

```
...RSQ QQQ F...
       ^^^
       это лишнее, если последовательность не должна оканчиваться на Q
```

Условие задачи запрещает оканчиваться на `Q`. Значит, нужно "перешагнуть" через хвост из `Q` и найти первый символ, который не `Q`:

```python
trueEnd = end + lenSubStr - 1  # временно: последний Q последнего RSQ

while trueEnd < lenData and data[trueEnd] == notEnd:
    trueEnd += 1
```

`trueEnd` начинает с позиции последнего `Q` последнего `RSQ` и ползёт вправо, пока видит `Q`. Как только встретил что-то другое — остановился. Это и есть настоящий конец последовательности.

Что если все символы до конца строки — `Q`?

```python
if trueEnd == lenData:
    continue  # такое окно не подходит — пропускаем
```

`trueEnd` дошёл до конца строки и не нашёл не-`Q`. Значит, это окно нарушает условие. Пропускаем.

---

#### Шаг пятый: считаем длину и обновляем минимум

```python
temp = data[bgn : trueEnd + 1]
lenTemp = len(temp)

if lenTemp < minLen:
    minLen = lenTemp
```

Вырезаем текущий кандидат — от начала первого `RSQ` до первого не-`Q` после последнего `RSQ`. Считаем длину. Если она меньше текущего минимума — обновляем.

`trueEnd + 1` в срезе — потому что Python не включает правую границу. Классика.

---

#### Итоговый код целиком

```python
with open("24_21717.txt", "r") as file:
    data = file.readline()

notEnd = 'Q'
repeat = 130
subStr = 'RSQ'

lenSubStr = len(subStr)
lenData = len(data)

indexes = []
for i in range(len(data) - lenSubStr + 1):
    if data[i : i + lenSubStr] == subStr:
        indexes.append(i)

minLen = float('inf')
for i in range(len(indexes) - repeat + 1):
    bgn = indexes[i]
    end = indexes[i + repeat - 1]

    trueEnd = end + lenSubStr - 1
    while trueEnd < lenData and data[trueEnd] == notEnd:
        trueEnd += 1

    if trueEnd == lenData:
        continue

    temp = data[bgn : trueEnd + 1]
    lenTemp = len(temp)

    if lenTemp < minLen:
        minLen = lenTemp

print(minLen)
```

Вася запускает. Окно скользит по строке $130$ `RSQ` за раз. Минимум найден. Число выведено.

**Вася завершился с `exit code 0`. На этот раз по-настоящему.**

---

> **Мораль:** Скользящее окно — это не магия и не сложный алгоритм. Это просто идея: вместо того чтобы каждый раз пересчитывать всё с нуля, двигай границы и обновляй только то, что изменилось. Как читать книгу: не перечитываешь с первой страницы каждый раз, когда переворачиваешь лист.
