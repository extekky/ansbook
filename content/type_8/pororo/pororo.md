### №59742 на Решу ЕГЭ

#### Условие

Определите количество четырёхзначных чисел, записанных в десятичной системе счисления, в записи которых **все цифры различны** и никакие две **чётные** и две **нечётные** цифры не стоят рядом.

#### Решение

```python
from itertools import product


def is_alternating(number):
    for i in range(len(number) - 1):
        if int(number[i]) % 2 == int(number[i + 1]) % 2:
            return False
    return True


count = 0

for number in product("0123456789", repeat=4):
    if number[0] == "0":
        continue

    if len(set(number)) != len(number):
        continue

    if not is_alternating(number):
        continue

    count += 1

print(count)
```

#### Как это работает

В этой задаче нужно перебрать все четырёхзначные числа и оставить только те, которые подходят под условия.

##### 1. Перебор всех вариантов

```python
for number in product("0123456789", repeat=4):
```

`product("0123456789", repeat=4)` перебирает все последовательности из четырёх цифр: от `0000` до `9999`.

Каждый `number` — это кортеж из символов, например:

```python
("1", "2", "3", "4")
```

##### 2. Отбрасываем числа с ведущим нулём

```python
if number[0] == "0":
    continue
```

Число не может начинаться с нуля, потому что тогда оно не будет четырёхзначным.

Например, `0123` — это не четырёхзначное число, а просто `123`.

##### 3. Проверяем, что все цифры различны

```python
if len(set(number)) != len(number):
    continue
```

`set(number)` оставляет только уникальные цифры.

Если длина множества меньше длины числа, значит какая-то цифра повторилась.

Например:

```python
number = ("1", "2", "2", "5")
set(number) = {"1", "2", "5"}
```

Длина была `4`, стала `3`, поэтому такое число не подходит.

##### 4. Проверяем чередование чётности

```python
def is_alternating(number):
    for i in range(len(number) - 1):
        if int(number[i]) % 2 == int(number[i + 1]) % 2:
            return False
    return True
```

Функция смотрит на каждую пару соседних цифр.

Если две соседние цифры имеют одинаковую чётность, число не подходит:

- обе чётные: `2` и `8`;
- обе нечётные: `3` и `7`.

Значит, цифры должны идти только с чередованием:

```text
чётная → нечётная → чётная → нечётная
```

или

```text
нечётная → чётная → нечётная → чётная
```

##### 5. Считаем подходящие числа

```python
count += 1
```

Если число прошло все проверки, увеличиваем счётчик.

В конце программа выводит:

```text
720
```

#### Ответ

```text
720
```
