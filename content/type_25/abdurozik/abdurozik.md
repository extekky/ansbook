#### №28711 на КЕГЭ

Вася читает условие. Вася видит число $2\,400\,000$. Вася видит слова **"простые множители"**. Вася видит условие про цифры $4$ и $7$.

Вася смотрит на это всё и думает: _а почему именно $4$ и $7$?_

Вася не находит ответа. Вася принимает это как данность и открывает Python.

---

#### Условие

Перебрать числа, большие $2\,400\,000$, и найти первые пять, которые представимы в виде произведения **ровно трёх различных простых множителей**, каждый из которых содержит в своей записи **хотя бы одну цифру $4$ или $7$**.

Для каждого из пяти чисел вывести само число и его **наибольший простой делитель**.

---

#### Декомпозиция: как Вася разбил страшную задачу на части

Условие звучит монолитно, но на деле это три независимые проверки для каждого числа:

1. У числа **ровно три различных простых делителя**
2. Произведение этих трёх делителей **равно самому числу** (то есть каждый входит ровно один раз)
3. В записи **каждого** из трёх делителей есть цифра `4` или `7`

Вася пишет по одной функции на каждую задачу. Вася не пишет всё в одну кучу. Вася читал про чистый код. Один раз. Мельком.

---

#### Функция первая: проверка простоты

```python
def prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True
```

Простое число — то, которое делится только на $1$ и на себя. Проверяем делители от $2$ до $\sqrt{n}$.

Почему до корня? Потому что если у числа есть делитель больше $\sqrt{n}$, то у него обязательно есть парный делитель **меньше** $\sqrt{n}$ — и мы его уже нашли бы. Например, у $21$ делители $3$ и $7$. $\sqrt{21} \approx 4.6$, поэтому $3$ мы поймаем в цикле, а $7$ — уже не нужен.

Вася не проверяет числа до $n$ включительно. Вася экономит время. Вася уважает процессор.

---

#### Функция вторая: поиск простых делителей

```python
def divisors(n):
    factors = set()
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if prime(d):
                factors.add(d)
            if prime(n // d):
                factors.add(n // d)
    return list(factors)
```

Снова идём до $\sqrt{n}$. Если `d` делит `n` — значит у нас пара делителей: `d` и `n // d`. Проверяем оба на простоту и добавляем в множество.

Почему `set()`, а не список? Потому что список может записать один и тот же делитель дважды. Например, у числа $4$: $d = 2$, $n // d = 2$ — оба одинаковые. Множество хранит только уникальные значения. **Вася не хочет считать одно простое число за два.**

---

#### Функция третья: проверка на цифры 4 и 7

```python
def has_4_or_7(n):
    return "4" in str(n) or "7" in str(n)
```

Самая лаконичная функция задачи. Переводим число в строку и проверяем наличие нужных символов.

- `47` → подходит
- `149` → подходит (есть `4`)
- `23` → не подходит

Вася мог написать цикл по цифрам. Вася не стал.

---

#### Основной цикл: перебираем числа

```python
count = 0
for number in range(2_400_001, 2_400_001 + 700):
    factors = divisors(number)
```

Начинаем с $2\,400\,001$ — первое число, большее $2\,400\,000$. Запас $700$ чисел взят с головой: первые пять подходящих находятся внутри этого диапазона. Если бы не нашлись — Вася бы увеличил запас. Вася действует методом научного тыка.

---

#### Три фильтра подряд

Дальше каждое число прогоняется через три проверки. Не прошёл — `continue`, следующий.

**Фильтр 1: ровно три различных простых делителя**

```python
if len(factors) != 3:
    continue
```

Нашли не три — не подходит. Пропускаем.

**Фильтр 2: произведение делителей равно числу**

```python
if factors[0] * factors[1] * factors[2] != number:
    continue
```

Это самый хитрый фильтр. Он отсекает числа, где простой делитель входит в разложение **несколько раз**.

Например, у числа $60 = 2^2 \cdot 3 \cdot 5$ простые делители — это $\{2, 3, 5\}$. Их три. Но $2 \times 3 \times 5 = 30 \neq 60$. Значит, $60$ не подходит — двойка входит дважды, а нам нужны **различные** множители, каждый ровно по одному разу.

А вот $30 = 2 \cdot 3 \cdot 5$ подходит: три различных простых, и $2 \times 3 \times 5 = 30$. ✓

**Фильтр 3: в каждом делителе есть 4 или 7**

```python
if not all(has_4_or_7(factor) for factor in factors):
    continue
```

`all(...)` возвращает `True` только если условие выполнено **для всех** элементов. Если хоть один делитель не содержит `4` или `7` — число отброшено.

---

#### Вывод результата

```python
print(number, max(factors))
count += 1
```

Число прошло все три фильтра — выводим его и наибольший простой делитель.

#### Итоговый код целиком

```python
def prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True

def divisors(n):
    factors = set()
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if prime(d):
                factors.add(d)
            if prime(n // d):
                factors.add(n // d)
    return list(factors)

def has_4_or_7(n):
    return "4" in str(n) or "7" in str(n)

count = 0
for number in range(2_400_001, 2_400_001 + 700):
    factors = divisors(number)

    if len(factors) != 3:
        continue
    if factors[0] * factors[1] * factors[2] != number:
        continue
    if not all(has_4_or_7(factor) for factor in factors):
        continue

    print(number, max(factors))
    count += 1
```

Вася запускает. Программа думает секунду. Программа выдаёт пять строк.
