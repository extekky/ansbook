### №28711 на КЕГЭ

#### Условие

Напишите программу, которая перебирает целые числа, большие $2\,400\,000$, в порядке возрастания и ищет среди них числа, представимые в виде произведения ровно **трёх различных простых множителей**, каждый из которых содержит в своей записи хотя бы одну цифру $4$ или $7$.

В ответе запишите первые **пять** чисел в порядке возрастания, справа от каждого числа запишите его наибольший простой делитель.

#### Решение

```python
def prime(n):
    if n < 2:
        return False

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True


def divisors(n):
    factors = set()

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if prime(d):
                factors.add(d)
            if prime(n // d):
                factors.add(n // d)

    return list(factors)


def has_4_or_7(n):
    return "4" in str(n) or "7" in str(n)


count = 0

for number in range(2_400_001, 2_400_001 + 700):
    factors = divisors(number)

    if len(factors) != 3:
        continue

    if factors[0] * factors[1] * factors[2] != number:
        continue

    if not all(has_4_or_7(factor) for factor in factors):
        continue

    print(number, max(factors))
    count += 1
```

#### Как это работает

В задачах типа 25 часто нужно проверить много чисел подряд и для каждого числа найти делители с нужными свойствами.

Здесь мы перебираем числа после $2\,400\,000$ и оставляем только те, которые подходят под три условия:

1. у числа ровно три различных простых делителя;
2. произведение этих трёх делителей равно самому числу;
3. в каждом простом делителе есть цифра `4` или `7`.

##### 1. Проверка простоты числа

```python
def prime(n):
    if n < 2:
        return False

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True
```

Функция `prime(n)` проверяет, является ли число простым.

Простое число имеет ровно два натуральных делителя: `1` и само себя.

Достаточно проверять делители только до корня из числа. Если у числа есть делитель больше корня, то второй парный делитель обязательно будет меньше корня.

Например, у числа $21$ делители $3$ и $7$. Один из них меньше $\sqrt{21}$, поэтому мы найдём делимость раньше.

##### 2. Поиск простых делителей

```python
def divisors(n):
    factors = set()

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if prime(d):
                factors.add(d)
            if prime(n // d):
                factors.add(n // d)

    return list(factors)
```

Функция `divisors(n)` ищет простые делители числа `n`.

Если `d` делит число `n`, то у него есть парный делитель:

```python
n // d
```

Например, если $60$ делится на $4$, то парный делитель равен $60 : 4 = 15$.

Мы проверяем оба числа из пары:

- сам делитель `d`;
- парный делитель `n // d`.

Если делитель простой, добавляем его в множество `factors`.

Множество `set()` нужно, чтобы один и тот же простой делитель не записался несколько раз.

##### 3. Проверка цифр 4 и 7

```python
def has_4_or_7(n):
    return "4" in str(n) or "7" in str(n)
```

Функция переводит число в строку и проверяет, есть ли в его записи цифра `4` или цифра `7`.

Например:

- `47` подходит;
- `149` подходит;
- `23` не подходит.

##### 4. Перебор чисел

```python
for number in range(2_400_001, 2_400_001 + 700):
```

Перебираем числа, начиная с $2\,400\,001$.

В коде взят запас в `700` чисел, потому что среди них уже находятся первые пять подходящих вариантов.

##### 5. Проверка количества простых делителей

```python
if len(factors) != 3:
    continue
```

Если у числа не ровно три различных простых делителя, оно сразу не подходит.

`continue` пропускает текущее число и переходит к следующему.

##### 6. Проверка произведения делителей

```python
if factors[0] * factors[1] * factors[2] != number:
    continue
```

Здесь проверяется, что произведение трёх найденных простых делителей равно самому числу.

Это отсекает числа, где какой-то простой делитель входит в разложение несколько раз.

Например:

```text
2 * 3 * 5 = 30
```

Число `30` подходит по этому условию.

А число `60` не подходит, потому что:

```text
60 = 2 * 2 * 3 * 5
```

У него тоже есть простые делители `2`, `3`, `5`, но их произведение равно `30`, а не `60`.

##### 7. Проверка всех простых делителей

```python
if not all(has_4_or_7(factor) for factor in factors):
    continue
```

`all(...)` возвращает `True`, только если условие выполнено для каждого элемента.

Значит, каждый простой делитель должен содержать цифру `4` или `7`.

##### 8. Вывод ответа

```python
print(number, max(factors))
```

Если число прошло все проверки, выводим:

- само число;
- его наибольший простой делитель.

2400427 461
2400433 1117
