Потом Вася перечитывает и понимает, что тройка — это три идущих подряд числа. Лошади отменяются. Вася вздыхает и открывает файл с данными.

---

#### Условие

В файле лежит последовательность целых чисел от $-100\,000$ до $100\,000$.

Нужно найти все **тройки** — три идущих подряд элемента — в которых выполняются **оба** условия:

1. **Хотя бы один** элемент тройки — трёхзначное число
2. Среднее арифметическое тройки **положительно** и **меньше максимального элемента последовательности, оканчивающегося на $28$**

В ответе: количество таких троек и максимальная сумма среди них.

---

#### Прежде чем писать цикл — разберёмся с условиями

Вася замечает, что условие составное и немного запутанное. Чтобы не потеряться, Вася раскладывает его по полочкам:

**Что такое "оканчивается на 28"?**
Число оканчивается на $28$, если его остаток от деления на $100$ равен $28$. Например: $128\ \%\ 100 = 28$ ✓, а $281\ \%\ 100 = 81$ ✗.

**Что такое "трёхзначное число" среди данных от $-100\,000$ до $100\,000$?**
Трёхзначные — это числа, у которых модуль от $100$ до $999$. Число $-345$ тоже трёхзначное — просто отрицательное. Поэтому берём `abs(elem)`.

**Порядок действий:**

1. Сначала найти `max_elem_28` — он нужен для проверки каждой тройки
2. Потом перебрать тройки и проверять оба условия

Вася составил план. Вася приступает.

---

#### Шаг первый: читаем файл

```python
with open("17_28938.txt") as file:
    data = [int(i) for i in file.readlines()]
```

`file.readlines()` возвращает список строк — по одной на каждую строку файла. Генератор списка `[int(i) for i in ...]` превращает каждую строку в число. На выходе — обычный список целых чисел `data`.

Вася открыл файл. Данные у Васи есть. Можно работать.

---

#### Шаг второй: ищем максимальный элемент, оканчивающийся на 28

```python
max_elem_28 = max([i for i in data if i % 100 == 28])
```

Генератор списка фильтрует только те числа, у которых последние две цифры — $28$. Из них `max()` берёт наибольшее.

**Пример:** если в данных есть $128$, $528$, $1028$ — `max_elem_28` будет $1028$.

Это число — **порог**: среднее каждой подходящей тройки должно быть меньше него.

---

#### Шаг третий: перебираем тройки

```python
for i in range(len(data) - 2):
    trio = [data[i], data[i + 1], data[i + 2]]
```

Индекс `i` пробегает от $0$ до `len(data) - 3` включительно — именно поэтому `range(len(data) - 2)`. Если бы цикл дошёл до последнего элемента, `data[i + 2]` вылетел бы за пределы списка. **Вася помнит про границы. Вася не получает `IndexError`.**

На каждом шаге `trio` — список из трёх соседних элементов.

---

#### Шаг четвёртый: проверяем трёхзначность

```python
if not (any(100 <= abs(elem) <= 999 for elem in trio)):
    continue
```

`any(...)` возвращает `True`, если **хотя бы один** элемент тройки удовлетворяет условию. Условие — модуль элемента от $100$ до $999$.

Если ни одного трёхзначного нет — `any` вернёт `False`, `not False` станет `True`, и `continue` пропустит тройку. Тройка не подходит — идём дальше.

Почему `abs(elem)`? Потому что $-345$ — вполне себе трёхзначное число. Вася не дискриминирует отрицательные числа.

---

#### Шаг пятый: проверяем среднее

```python
avarage = sum(trio) / 3
if not (avarage > 0 and avarage < max_elem_28):
    continue
```

Считаем среднее и проверяем два условия одновременно:

- среднее **больше нуля** — тройка в целом положительная
- среднее **меньше** `max_elem_28` — не превышает порог

Если хотя бы одно условие нарушено — `continue`, тройка отброшена.

---

#### Шаг шестой: тройка подошла — фиксируем результат

```python
max_sum_trio = max(max_sum_trio, sum(trio))
count += 1
```

`count` считает количество подходящих троек. `max_sum_trio` обновляется, если сумма текущей тройки больше предыдущего максимума.

Почему не храним все суммы в списке? Не нужно: максимум можно обновлять на лету. Вася экономит память.

---

#### Итоговый код целиком

```python
with open("17_28938.txt") as file:
    data = [int(i) for i in file.readlines()]

max_elem_28 = max([i for i in data if i % 100 == 28])

count = 0
max_sum_trio = 0

for i in range(len(data) - 2):
    trio = [data[i], data[i + 1], data[i + 2]]

    if not (any(100 <= abs(elem) <= 999 for elem in trio)):
        continue

    avarage = sum(trio) / 3
    if not (avarage > 0 and avarage < max_elem_28):
        continue

    max_sum_trio = max(max_sum_trio, sum(trio))
    count += 1

print(count)
print(max_sum_trio)
```

Вася запускает. Программа перебирает тройки. Программа находит нужные. Программа выводит два числа.
